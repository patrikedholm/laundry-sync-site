Privacy policy

laundry-sync · last updated 4 October 2026

laundry-sync is a personal, single-user application. Its only user is its owner, and it processes only the owner’s own data.

Google account data

Sign-in. Signing in with Google gives the app the account’s stable Google account id and email address. They are stored to recognise the owner, and no other account is let in.

Calendar access. When the owner connects Google Calendar, the app receives an OAuth refresh token, which it stores in its own database. It uses that access only to list the calendars the owner can write to, and to create, update, read and delete the events that represent laundry bookings in the calendar the owner has chosen. It does not read or change any other events.

Other data

The app stores the owner’s settings (target calendar, reminders, event text) and a mapping from each laundry booking to its calendar event. Credentials for the laundry booking system are supplied as configuration and are not stored in the database.

Sharing

No data is sold, shared with third parties, used for advertising, or used to train any model. Data is sent only to Google’s Calendar API and to the laundry booking system, as needed for the sync.

laundry-sync’s use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Retention and removal

Data is kept while the app is in use. The owner can revoke the app’s access at any time at myaccount.google.com/connections; the app then discards the stored token the next time it tries to use it. Deleting the app’s database removes everything it has stored.

Contact

Questions can be raised with the maintainer via github.com/patrikedholm.
